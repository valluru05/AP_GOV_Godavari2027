# Application Screenshots & Visual Demonstrations

This directory is designated for repository screenshots capturing the key modules of CivicProof:

- `dashboard.png` — Executive Overview Dashboard & Readiness Gauge
- `projects.png` — Municipal Infrastructure Project Register & Milestones
- `inspection.png` — Geofenced Field Inspection & Statutory Checklist
- `assets.png` — Municipal Asset Registry & Lifecycle Tracking
- `qr-scanner.png` — Live Hardware Camera QR Code Scanner

To capture screenshots:
1. Access the live portal at [https://civicproofap-gov-godavari2027.vercel.app](https://civicproofap-gov-godavari2027.vercel.app)
2. Use the 1-Click Persona Switcher to navigate through the modules.
3. Save screenshots into this directory matching the names above.
